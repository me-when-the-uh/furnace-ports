# Namco C352 instrument editor

the C352 instrument has Sample and Macros tabs. assign an initial sample or use the note-to-sample map as described in the [Sample instrument editor](sample.md).

## Macros

- **Volume**: 0–255.
- **Arpeggio**: pitch sequence, in semitones.
- **Panning (left/right)**: 0–255. each side controls the front outputs. the rear pair follows the song's surround panning.
- **Pitch**: -2048–2047, with absolute or relative mode.
- **Phase Reset**: 1 restarts the current sample from its beginning.

the generic Sample instrument is also accepted, with its existing volume (0–64) and panning (0–127) ranges. C352 instruments store their sample map and macros using the existing sample-instrument features; instrument type is 68.

see [C352 system](../7-systems/c352.md) for sample formats, bank and loop limits. hardware FM and FILTER controls are not exposed. LINK is applied automatically to samples whose loop spans more than one bank.
