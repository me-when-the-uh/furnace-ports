# Namco C352

Furnace's C352 implementation provides 32 PCM voices, independent panning and a 16 MiB sample ROM. samples use signed 8-bit PCM, C219 compressed PCM, C352 mu-law, or 16-bit data holding mu-law-decoded values. 16-bit data is re-encoded to mu-law bytes when rendered.

the default clock is 25401600 Hz, with a fixed divider of 288 (88200 samples per second). a custom clock changes the sample rate to clock / 288. System 22 boards run the chip at 24576000 Hz, and the rips of those games carry that same clock.

## instruments and samples

use the [C352 instrument editor](../4-instrument/c352.md), or the generic Sample instrument.

- each sample must fit entirely in a 64 KiB bank. Furnace automatically pads to the next bank when necessary.
- a non-looping sample may contain at most 65535 bytes, followed by one silent guard byte.
- a looping sample must fit one 64 KiB bank per segment. a loop longer than a bank is split into the intro and the loop region, placed in separate banks and joined by the hardware LINK jump.
- forward and ping-pong loops are supported. backward loops are rejected. loop end is exclusive in the editor; loop start must precede it and loop end must not exceed sample length.
- a one-sample ping-pong loop behaves as a forward loop. empty samples and invalid loops are rejected.
- the ROM limit includes bank padding and guard bytes. samples which cannot fit are not loaded; check Sample ROM usage in the sample editor.

## chip configuration

**Four outputs (front L/R, rear L/R)** enables four separate outputs in that order. the default stereo mode sums front and rear for each side: L=FL+RL, R=FR+RR. panning macros and channel panning drive the front pair. the rear pair stays silent unless the song uses surround panning. use the patchbay to route four-output audio.

**Custom clock rate** overrides the default clock. both settings are retained in `.fur` songs.

## VGM export

the export writes the C352 register stream (`0xE1`) and up to 16 MiB of sample ROM (`0x92`), with the header clock divider field set. 32 voices are exported; the ROM is written as placed by the sample renderer, including the second bank of split loops.

## limitations

hardware FM, FILTER and undocumented control behavior are not exposed as instrument or chip settings. the debugger provides the common channel state and the 16-bit register sheet.

the `.fur` system ID is `0xd0`, the format's reserved ID for the chip.
